# 金融智能客服项目

本仓库保留原有电商小二教学代码，并新增可独立运行的金融智能客服演示服务，覆盖账户、银行卡、贷款、理财、基金、信用卡及投诉业务。

## 快速启动

```powershell
cd E:\AICoding\finance\customer-service-backend
uv run --project .. python finance_demo.py
```

打开 `http://127.0.0.1:18083`。服务启动后会在 `customer-service-backend/finance_demo.db` 自动创建 SQLite 数据库；它保存聊天记录、当前流程槽位及贷款申请/挂失/投诉事件，重启后可恢复。

## 演示范围

- 账户查询：输入“帮我查一下账户余额”，再输入 `6222020000001234`。
- 交易查询：输入“查询昨天的消费记录”，按提示输入银行卡号和日期。
- 贷款查询：输入“查询贷款状态”，再输入 `LN202608270001`。
- 贷款申请：收集贷款类型、金额、期限、用途，生成申请编号。
- 信用卡挂失：收集卡号、原因、身份验证信息，生成受理编号。
- 投诉工单：收集交易流水号、投诉类型、问题描述，生成工单编号。
- 产品咨询：支持理财、基金、贷款和信用卡产品介绍。

办理过程中可随时切换到另一项查询；系统会将当前槽位状态持久化，待新任务完成或取消后自动恢复此前流程。

## 接口

- `POST /api/chat`：处理一轮对话，返回识别意图、回复、当前任务和槽位。
- `GET /api/chat/history?sender_id=demo-user`：读取历史消息。
- `GET /api/session/{sender_id}`：读取已持久化的会话状态。
- `GET /api/events/{sender_id}`：读取已完成任务的业务事件。
- `GET /api/demo-data`：读取金融样本数据。

样本数据位于 `customer-service-backend/finance_sample_data.json`，来源于需求资料中定义的账户、交易、理财、基金、信用卡和贷款产品业务对象，并进行了可直接演示的精简配置。
